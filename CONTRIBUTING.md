# Contributing to Ruxon Engine

## Getting Started
1. Read the [Master Plan](RUXON_ENGINE_MASTER_PLAN.md) if it exists
2. Follow the house rules in the plan
3. Build and test before submitting

## Code Style
- C++20
- Follow existing patterns
- Keep it simple and readable

## Testing
- All tests must pass
- Build on all platforms via CI

## Commits
- Clear, descriptive commit messages
