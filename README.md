# Ruxon Engine

[![Support on SociaBuzz](https://img.shields.io/badge/Support%20on%20SociaBuzz-%E2%9D%A4%EF%B8%8F-f97316?style=for-the-badge&logo=ko-fi&logoColor=white)](https://sociabuzz.com/zerobyte/tribe)

A free, fully open source game engine and editor for making 2D and 3D games, written in C++20 with OpenGL.

## Goals

- 2D and 3D in one engine and one editor
- Visual editor inspired by Godot - scene tree, inspector, viewport, play button
- Three ways to write game logic: Ruxon Script (custom English-like language), C++, and C (through stable C interface)
- Cross-platform: Windows, Linux, macOS
- Lightweight with optional modules
- Totally open source and free, no royalties, no accounts, no telemetry
- BYOK AI assistant (Bring Your Own Key)
